# 对比机场时先看这四项

这篇不推荐具体品牌，也没有购买链接。合理的做法是先把列定好，再填每一家。

## 推荐的顺序

1. **域名。** 只认你自己核对过的那一个主机名。搜索广告、私聊「备用域名」、多一个字母的仿站，不进入对比。
2. **流量。** 记下每月额度、哪一天重置、用完之后是限速还是断开。写「不限」但没有重置日的，不要和写明额度的放在同一列。
3. **客户端。** 只从核对过的域名下载。要先安装来历不明的包才能看到价格的，这一家不进入对比。
4. **退款。** 条件要写在套餐页或付款页上。只在聊天里答应的，按没有退款记。

## 不建议

- 不建议列不齐就打分。
- 不建议把没核对过的域名写进同一张表。

一家一行，四列填完再排序。
